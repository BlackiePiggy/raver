# iOS Event Upload Flow V2 QA Checklist

## 灰度开关

- 默认保持旧 `EventEditorView`。
- DEBUG 可通过 `RAVER_EVENT_UPLOAD_FLOW_V2_ENABLED=1` 或 `AppConfig.setEventUploadFlowV2Enabled(true)` 打开 V2。
- 需要验证入口：
  - Discover 活动新增。
  - Discover 活动详情编辑。
  - Profile / 我的发布 / 发布活动。
  - Profile / 我的发布 / 编辑活动。

## 新建活动主流程

- 无 Poster 时不能继续提交。
- 六区图片均可添加：poster、lineup、timetable、cover、map、other。
- 图片支持相册多选、拍照、替换、删除、排序。
- AI 按钮只展示占位提示，不应触发识别或提交。
- 基础信息必须填写活动名称、城市、国家、详细地址。
- 新建活动必须通过城市时区搜索确认 timezone。
- 时间页应展示活动城市时区与当前设备时区预览。
- 地图选点可选；选点后回填地址信息；无坐标但有手动地址可提交。
- 阵容可跳过。
- 阵容可手动添加 DJ，支持 Solo / B2B / B3B。
- DJ 库搜索绑定可回填 DJ 名称并保留手动名称 fallback。
- 时间表 slot 支持 Day / Week-Day、舞台、开始和结束时间。
- 结束时间不晚于开始时间时，提交 payload 按次日结束处理。
- 票务只验证最低价、最高价、币种、购票链接。

## 提交结果

- 管理员或可绕过审核角色：直接创建活动，成功页提示已发布。
- 普通用户：进入审核，成功页提示可在我的发布查看进度。
- 提交失败时保留草稿和本地图片，可重试。
- 提交成功后清理对应草稿。
- 成功页点击返回活动页后退出上传流程。
- 我的发布列表在保存通知后刷新。

## 草稿

- 新建活动每个用户只保留一份草稿。
- 再次进入新建活动时提示继续草稿或重新开始。
- 编辑活动按 event id 独立保存草稿。
- 草稿超过 14 天自动过期并清理对应图片目录。

## 真机权限

- 相册权限：首次选择图片时应出现系统授权。
- 相机权限：首次拍照时应出现系统授权。
- 地图权限：使用当前位置时应出现系统定位授权。
- 切后台后返回，草稿不丢失。
- 键盘弹出时各步骤输入框可滚动到可见区域。

## 主题

- 跟随系统 Light / Dark。
- 至少检查媒体、基础信息、时间、地点、阵容、预览、成功页。
- 文本不能溢出按钮、卡片或底部栏。
