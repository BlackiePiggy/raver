# EDMTI 人格结果页流派推荐与标签建议

日期：2026-06-13

## 重新校准说明

上一版为了满足“每个人格 4 到 5 个库内流派”，有些扩展项贴合度不够。这一版改成严格按人格介绍、genreMapping、听感关键词来选，并且只使用当前 Genre 库里已经存在的电子音乐流派。

使用口径：

- 主推荐：最符合人格核心气质，适合直接作为结果页可点击标签
- 延展推荐：也符合这个人格，但更适合用于“相似风格 / 推荐歌单 / 更多探索”
- 当前执行口径：每个人格下列出的 5 个流派都作为结果页可点击绑定标签
- 对隐藏人格和玩梗人格，也按同样口径绑定 5 个标签，让结果页体验保持一致

## 每个人格推荐

### 1. `DROPI / 会场拳击手`

人格关键词：前排、急脾气、drop 导向、重鼓、规整炸裂、控场。

推荐流派：

- `Big Room House`：主舞台 drop、强冲击、最贴近“会场拳击手”的大场景能量
- `Hardstyle`：硬底鼓、强节奏、适合“铺垫太长就想快进”的直给型人格
- `Hardcore`：更极端的硬核能量，承接“重鼓点”和前排冲击
- `Hard Dance`：比 `Hardstyle` 更宽，适合覆盖硬派舞曲取向
- `Hard Trance`：如果想保留旋律和硬派推进的结合，可以作为延展项

### 2. `BOUN / 栏杆摧毁者`

人格关键词：快乐至上、Bounce、弹跳、洗脑循环、全程蹦跳、社交带动。

推荐流派：

- `Melbourne Bounce`：核心标签，最准确承接“弹跳快乐”和反拍律动
- `Big Room House`：适合大型现场、热门炸场和全场一起跳
- `Future House`：更轻快、更现代，适合快乐明亮的 bounce 气质
- `Electro House`：作为 `Melbourne Bounce` 的上位语境，适合保留
- `Eurodance`：如果要表现大众、快乐、洗脑和复古商业舞曲感，可以作为延展项

### 3. `HUG / 抱抱摇`

人格关键词：温柔、治愈、旋律、照顾别人、情绪急救包。

推荐流派：

- `Melodic Bass`：比泛泛的 `Future bass` 更贴近“温柔但有情绪 drop”的核心
- `Future bass`：柔和和弦、人声切片、治愈感明确
- `Melodic Dubstep`：适合情绪更浓、drop 更有释放感的旋律系人格
- `Progressive House`：温柔递进、旋律线清晰，适合歌单分享型人格
- `Vocal Trance`：如果强调陪伴和情绪共鸣，可以作为延展项

### 4. `OLD / 电音老登`

人格关键词：80/90 年代、复古、经典、老派四拍、拒绝网红歌。

推荐流派：

- `Disco`：最贴近复古舞池和“爸妈当年蹦迪”的核心画面
- `Classic Chicago House`：经典 house 的明确落点，比泛称 Classic House 更稳
- `Chicago House`：老派四拍、俱乐部根源感强
- `Acid House`：适合补充 80/90 年代电子舞曲的历史质感
- `Eurodance`：如果想表现 90 年代大众舞曲记忆，可以作为延展项

### 5. `PROD / 待就业Producer`

人格关键词：编曲细节、层次递进、BPM 分类、精准和声、结构控。

推荐流派：

- `Progressive House`：结构递进和层次编排最符合这个人格
- `Progressive Trance`：比泛 `Trance` 更贴近“递进控”和长线编排
- `Melodic Progressive Trance`：适合强调旋律、和声、推进感的技术型听众
- `Trance`：保留传统 trance 审美和规整四拍框架
- `Melodic Techno`：适合从制作细节、音色层次、长线旋律角度延展

### 6. `HEAD / 反差BASS佬`

人格关键词：低频、炸头、深夜耳机、宣泄、重 drop、社恐自嗨。

推荐流派：

- `Hardstyle`：硬派低频和宣泄感都很贴
- `Hardcore`：更重、更直接，适合“炸穿天花板”
- `Aggressive Dubstep`：比泛 `Bass Music` 更符合“耳机炸头”和低频冲击
- `Industrial Hardcore`：适合更黑、更失真、更强硬的版本
- `Big Room House`：如果需要保留大型炸场感，可以作为延展项

### 7. `NIGHT / 现场见？`

人格关键词：深夜、被窝、私藏、温柔舒缓、慢电音、睡前听。

推荐流派：

- `Chillwave`：比泛 `Chill-out` 更贴近“深夜、柔化、朦胧”的听感
- `Downtempo`：适合慢速、睡前、弱化重鼓的氛围
- `Chillstep`：保留 future bass / dubstep 的柔和低频，但不太炸
- `Future bass`：适合温柔和弦与人声切片
- `Ambient`：作为更安静、更沉浸的延展项

### 8. `DREAM / 孤独患者`

人格关键词：小众、迷幻、宇宙漫游、空灵、长线旋律、独处沉浸。

推荐流派：

- `Uplifting Trance`：最直接承接空灵、上扬、穿梭感
- `Melodic Techno`：适合孤独、沉浸、长线旋律
- `Progressive Trance`：比泛 `Trance` 更适合漫游式推进
- `Psybient`：适合迷幻、宇宙、独处氛围
- `Space Ambient`：如果强调宇宙感和画面感，可以作为延展项

### 9. `DARK / 小众哥`

人格关键词：地下、工业冷感、先锋、冷门、审美鄙视链、反商业。

推荐流派：

- `Industrial Techno`：核心标签，最符合地下工业冷感
- `Experimental`：承接先锋实验和反商业审美
- `Dark Ambient`：适合更冷、更压抑、更地下的氛围延展
- `Industrial Ambient`：工业质感和氛围实验的交集
- `EBM`：适合更硬、更身体化的地下工业舞曲取向

### 10. `MASH / 缝合怪本怪`

人格关键词：混搭、remix、全曲风融合、创意重组、玩法大于流派。

推荐流派：

- `Experimental`：最适合承接“什么都敢缝”的实验态度
- `IDM (Intelligent Dance Music)`：适合复杂结构和非传统编排
- `Glitch Hop`：适合拼贴、故障、节奏重组
- `Complextro`：适合复杂音色切片和高密度编排
- `Breakbeat`：适合打破四拍、增加混搭节奏感

### 11. `PARTY / 局头`

人格关键词：组局、社交、热情、正能量、带人入坑、燃系。

推荐流派：

- `Uplifting Trance`：昂扬、正向、热血，很贴“局头”的情绪核心
- `Progressive House`：大众友好、旋律推进、适合带人入坑
- `Big Room House`：适合大合唱和集体炸场
- `Vocal Trance`：适合强调治愈、热血和人声共鸣
- `House`：作为最稳的大众舞池底盘

### 12. `SUNNY / 气氛组组长`

人格关键词：明亮、轻快、活力、新鲜感、分享欲、气氛组。

推荐流派：

- `Future House`：轻快、明亮、现代，最贴“阳光”和新鲜感
- `Progressive House`：清新、旋律化、适合分享和大众接受
- `Melbourne Bounce`：承接轻快弹跳和现场气氛
- `Melodic House`：比泛 `House` 更贴近明亮旋律感
- `Dance-pop`：如果想表现轻松、大众、好入口，可以作为延展项

### 13. `COLD / Techno高级感判官`

人格关键词：极简、冷感、低饱和、不混圈、拒绝网红、Techno 高冷党。

推荐流派：

- `Minimal Techno`：核心标签，最准确
- `Dub Techno`：冷、深、克制，适合高级感和低饱和
- `Deep Techno`：更沉、更内敛，适合独处型 techno 审美
- `Ambient Techno`：适合冷感空间和氛围延展
- `Industrial Techno`：如果想保留更硬、更冷的工业边界

### 14. `GLIT / Virtual Riot线上学员`

人格关键词：音色拆解、技术流、故障感、复杂编曲、研究型听众。

推荐流派：

- `Complextro`：最贴近复杂音色切片和技术炫技
- `Glitch Hop`：适合故障音色和节奏拆解
- `IDM (Intelligent Dance Music)`：适合研究型、复杂结构型听感
- `Color Bass`：适合明亮复杂的现代 bass 音色设计
- `Melodic Brostep`：贴近 Virtual Riot 语境中的旋律化重 bass

### 15. `AMBI / 浪漫主义逃犯`

人格关键词：空灵、声场、宇宙、幻境、脑补故事、浪漫主义。

推荐流派：

- `Ambient`：核心标签，最稳
- `Space Ambient`：最贴近宇宙、空灵、画面感
- `Psybient`：适合迷幻和沉浸式梦境
- `Progressive Trance`：如果需要保留 dream trance 的长线推进
- `Ambient Techno`：适合更电子、更律动但仍然氛围化的版本

### 16. `PLUR / 佛系电子难民`

人格关键词：佛系、松弛、纯粹好听、无攻击性、治愈纯旋律。

推荐流派：

- `Chillwave`：最贴近 healing、温柔、低攻击性
- `Downtempo`：松弛、慢速、适合佛系听歌
- `Chill-out`：宽而稳，适合作为主标签
- `Future bass`：保留纯旋律和温柔电子质感
- `Melodic Bass`：如果想让旋律和情绪更明确，可以作为延展项

### 17. `DRUNK / 酒鬼蹦迪人`

人格关键词：喝酒、断片、现场状态、从开场蹦到散场、什么都好听。

推荐流派：

- `Big Room House`：最适合大型现场和集体高能
- `Melbourne Bounce`：适合喝嗨后的简单、直接、弹跳
- `Hardstyle`：适合后半场更硬、更冲的蹦迪状态
- `Eurodance`：适合大众、快乐、上头、容易跟着动
- `Moombahton`：适合酒后更松、更摇摆的派对律动

### 18. `HHHH / 傻乐者`

人格关键词：听什么都开心、不挑曲风、纯粹快乐、低门槛。

推荐流派：

- `Happy Hardcore`：名字和情绪都贴，快乐、直接、能量高
- `Kawaii future bass`：可爱、明亮、轻松，适合“傻乐”
- `Dance-pop`：大众友好、快乐、没有门槛
- `Eurodance`：简单、洗脑、快乐，适合纯粹开心
- `Melbourne Bounce`：如果需要现场蹦跳感，可以作为延展项

### 19. `CPDD / 搭子狂魔`

人格关键词：找搭子、组队、热闹、社交、热门炸场、大众燃系。

推荐流派：

- `Melbourne Bounce`：适合组队蹦、反复弹跳、氛围直给
- `Big Room House`：最适合大众炸场和集体高光
- `Future House`：轻快、好入口，适合社交场景
- `Dance-pop`：大众接受度高，适合“找搭子”的低门槛
- `Progressive House`：适合旋律更明亮、情绪更正向的版本

### 20. `PHOENIX / 凤凰很行`

人格关键词：Illenium、未来贝斯、温柔撕裂、情绪递进、治愈但会爆发。

推荐流派：

- `Melodic Bass`：最贴近 Illenium 式情绪 bass
- `Future bass`：核心标签，柔和和弦和情绪 drop 明确
- `Melodic Dubstep`：比泛 `Dubstep` 更贴近“温柔撕裂”
- `Chillstep`：适合治愈、氛围和柔和低频
- `Melodic Brostep`：如果要保留更重、更炸但仍旋律化的 drop

## 执行建议

- 结果页标签按本文档每个人格的 5 个推荐全部绑定
- 推荐歌单、相似流派、人格详情页可以复用同一组 5 个标签，保持用户认知一致
- 落库时需要确保 20 个结果全部拥有 5 个 genreBindings，也就是总绑定数为 100
