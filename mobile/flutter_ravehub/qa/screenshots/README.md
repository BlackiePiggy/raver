# RaveHub Screenshot Parity Artifacts

This folder stores native iOS reference screenshots for Flutter pixel-parity
comparison.

## Reference Directory

- `qa/screenshots/ios-reference/*.png`

Reference filenames must match the Flutter capture filenames exactly. The
current development-preview capture set is:

- `login_initial.png`
- `discover_picks.png`
- `discover_events.png`
- `discover_sets.png`
- `circle_feed.png`
- `circle_squads_login.png`
- `circle_id.png`
- `circle_ratings.png`

## Flutter Artifact Directory

- `app/build/screenshots/flutter/*.png`
- `app/build/screenshots/diff/*.png`

These files are generated by
`app/integration_test/flows/screenshot_parity_flow_test.dart` and collected by
`app/scripts/collect_macos_screenshot_artifacts.sh`.

## Baseline Capture State

- Device viewport: 393 x 852 logical pixels
- Pixel ratio: 3.0
- Output size: 1179 x 2556 pixels
- Locale: English
- Theme: app default dark theme
- Text scale: Flutter test default
- Account state: unauthenticated public preview
- Live service: `https://api.ravehub.top`

Native iOS reference screenshots should be captured with the same locale, theme,
font scale, account state, and device geometry before enabling strict pixel
comparison.
